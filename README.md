# NxtWave Growth Engine — React Prototype

Professional frontend prototype for the NxtWave Growth Intern Growth Challenge.

## Run

npm install
npm run dev

## Build

npm run build

## Stack

- React + Vite
- Framer Motion
- Lucide React
- Responsive CSS
- Frontend only; no backend/database

## Demo

- Simulate referral increments campaign + personal referral count.
- Copy referral link.
- Toggle live simulation.
- Animated leaderboard and channel cards.

All registration numbers are simulation assumptions for the challenge.
